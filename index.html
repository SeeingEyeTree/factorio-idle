Quick Reference

            
place(type, arg, n) — queue a building

            
craft(item, n) — add to craft queue

            
research("name") — start research

            
fortify(type, n) — add walls / turrets

            
limit(type, n) — set output limit

            
print(value) — log to output

Memory (persists between runs)

x = MEM_A — read persistent value

            
Any MEM_* name works (A–Z or custom)
